Commitment Stake

A Web3-powered deposit system designed to eliminate no-shows at student events. Participants stake crypto tokens via a smart contract to register. Checking in at the event via QR code triggers an automated refund. If a participant fails to show up, their staked deposit is trustlessly distributed among those who attended.

Key Features

- Smart Contract Escrow: Event deposits are locked securely on-chain, removing the need for a centralized middleman to hold funds.

- Trustless Settlement: Post-event reconciliation is handled by the smart contract. No-show penalties are automatically and transparently distributed to the Web3 wallets of actual attendees.

- QR-to-Chain Verification: Seamless physical check-in using QR codes that instantly triggers state updates and token transfers on the blockchain.

- Immutable Transparency: All event registrations, check-in statuses, and financial distributions are permanently verifiable on the public ledger.

Tech Stack
- Backend: Golang (QR generation, high-concurrency API processing)

- Blockchain: Solidity (Smart Contracts), Web3/RPC Integration

- Database: MYSQL (Off-chain indexing and user metadata)
